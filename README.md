# LUCID---Accenture-Innovation-Challenge-2026
LUCID — an AI reasoning layer that turns KPI anomalies into evidence-backed business decisions. Detects statistically real deviations, attributes them to the driving segment, writes a cited What/Why/So-What/Now-What story, and stays honest when evidence is ambiguous instead of guessing. Zero-dependency, single-file prototype — works on any dataset.
